# Lärloop

Lärloop är en statisk, svenskspråkig studieplattform. Öppna `index.html` lokalt
eller publicera sidan med GitHub Pages.

## Publicering

Webbplatsen publiceras automatiskt till GitHub Pages när ändringar pushas till
`main`. Arbetsflödet ligger i `.github/workflows/pages.yml`. Den publicerade
sidan finns på <https://80dkk.github.io/larloop/>.

## Om AI-funktionerna

Textcoachen, studiekompisen och materialverktyget är lokala, interaktiva
demonstrationer. De skickar inte text till en AI-tjänst. En riktig
AI-integration kräver en serverdel och en konfigurerad AI-leverantör.
